// manual testing

Manual testing approach

📝

Test planning

Creating detailed test plans aligned with business requirements, defining scope, objectives, and entry/exit criteria.

  • Test strategy documents
  • Resource estimation
  • Risk analysis
🔍

Test case design

Writing clear, reusable test cases using BVA, equivalence partitioning, and decision table techniques.

  • Positive & negative cases
  • Edge case identification
  • Traceability matrix
🧭

Exploratory testing

Unscripted testing sessions to find unexpected defects that scripted tests often miss, using session-based charters.

  • Session-based testing
  • Mind-map exploration
  • Heuristic evaluation
🐛

Bug reporting

Writing clear, reproducible bug reports with steps, expected vs actual results, severity, and supporting evidence.

  • JIRA bug tracking
  • Severity classification
  • Root cause notes
🔄

Regression testing

Systematically verifying that existing functionality is not broken by new changes, using risk-based prioritisation.

  • Full & partial regression
  • Smoke & sanity checks
  • Release sign-off
👥

UAT support

Supporting user acceptance testing by preparing test scenarios, guiding stakeholders, and tracking feedback.

  • UAT test script prep
  • Stakeholder walkthroughs
  • Defect triage
